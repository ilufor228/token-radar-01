The model: how an implied value is made, and what happens if you move it

Each protocol's record gives four signals, each scored 0 to 1. Their weighted sum is a radar score out of 100. The score sets an implied value using an exponential scale.

score    = 55·scale + 25·momentum + 15·tenure + 5·breadth
scale    = log10(tvl / $1M) / log10(3000)         clipped to 0..1
momentum = (clamp(change_7d, -60, +120) + 60) / 180
tenure   = days since DefiLlama first saw it / 1825, clipped to 0..1
breadth  = (chains - 1) / 4, clipped to 0..1

implied  = round($500,000 · 10^(score · 0.024))

A record with no seven-day reading scores 0.5 on momentum; one with no start date scores 130 days of tenure; one naming no chain scores 0. Protocols in this same snapshot that do trade sit at a median market-cap-to-TVL of —.

Moving a weight re-ranks the board in the page. board.json stays the model above; this is what-if only.
